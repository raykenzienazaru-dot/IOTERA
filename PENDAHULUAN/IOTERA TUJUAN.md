A. Tujuan Umum

Mengembangkan IOTERA (IoT Engineering & Recommendation Assistant), sebuah platform berbasis web yang memanfaatkan Artificial Intelligence, Machine Learning Recommendation, Speech Recognition, dan visualisasi 3D untuk membantu pengguna menerjemahkan aspirasi atau gagasan menjadi rancangan awal proyek IoT yang interaktif dan dapat dikembangkan.

B. Tujuan Khusus

1. Menyediakan media penyampaian ide melalui input teks dan suara sehingga pengguna dapat menyampaikan aspirasi proyek IoT tanpa harus memahami istilah teknis secara mendalam.
2. Menganalisis ide pengguna menggunakan AI untuk mengidentifikasi kebutuhan dan tujuan dari proyek IoT yang ingin dikembangkan.
3. Memberikan rekomendasi komponen IoT seperti mikrokontroler, sensor, aktuator, dan komponen pendukung berdasarkan kebutuhan proyek menggunakan Machine Learning Recommendation dan component library.
4. Mengubah hasil rekomendasi menjadi rancangan prototype 3D, sehingga keluaran sistem tidak hanya berupa teks, tetapi dapat divisualisasikan dan dipahami secara lebih konkret.
5. Menyediakan lingkungan perancangan 3D interaktif yang memungkinkan pengguna melihat, memindahkan, menambahkan, dan menghapus komponen IoT dalam rancangan.
6. Memungkinkan pengguna menambahkan komponen dan kabel jumper secara mandiri melalui fitur Add Component dan Add Jumper sebagai bentuk pengembangan rancangan berdasarkan kebutuhan pengguna.
7. Membantu memeriksa hubungan antar-komponen melalui validasi dasar terhadap koneksi pin dan kompatibilitas komponen dalam rancangan IoT.
8. Menyediakan rancangan awal yang dapat dikembangkan menuju implementasi nyata, sehingga IOTERA dapat menjadi jembatan antara aspirasi pengguna, rekomendasi AI, dan proses pengembangan prototype IoT.
