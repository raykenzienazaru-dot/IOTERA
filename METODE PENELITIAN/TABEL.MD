## Tabel Penjelasan User Flow IOTERA

| Tahap | Fitur / Proses | Penjelasan |
| :---: | :--- | :--- |
| 1 | **Akses IOTERA** | Pengguna membuka website IOTERA untuk memulai proses perancangan proyek IoT. |
| 2 | **Register / Login** | Pengguna membuat akun baru atau masuk menggunakan akun yang telah terdaftar. |
| 3 | **Dashboard** | Pengguna dapat melihat proyek yang telah tersimpan atau membuat proyek IoT baru. |
| 4 | **Create New Project** | Pengguna membuat proyek baru dan mulai menyampaikan kebutuhan atau ide yang ingin dikembangkan. |
| 5 | **Text Input** | Pengguna menyampaikan ide dan kebutuhan proyek IoT dalam bentuk teks. |
| 6 | **Voice Input** | Pengguna dapat menyampaikan ide melalui suara yang kemudian dikonversi menjadi teks menggunakan Speech Recognition. |
| 7 | **AI Analysis** | AI menganalisis input untuk memahami tujuan, fungsi, dan kebutuhan proyek pengguna. |
| 8 | **Component Recommendation** | Sistem merekomendasikan mikrokontroler, sensor, aktuator, dan komponen pendukung berdasarkan hasil analisis. |
| 9 | **Generate Prototype 3D** | Sistem mengubah hasil rekomendasi menjadi rancangan awal proyek IoT dalam bentuk prototype digital 3D. |
| 10 | **3D Workspace** | Pengguna dapat melihat, memutar, memperbesar, dan mengeksplorasi rancangan melalui lingkungan 3D interaktif. |
| 11 | **Add Component** | Pengguna dapat menambahkan sensor, aktuator, mikrokontroler, atau komponen lain dari Component Library. |
| 12 | **Add Jumper** | Pengguna dapat membuat koneksi antar-pin menggunakan kabel jumper secara visual pada rancangan 3D. |
| 13 | **Edit Component** | Pengguna dapat memindahkan, mengatur posisi, atau menghapus komponen sesuai kebutuhan rancangan. |
| 14 | **Validate Project** | Sistem melakukan validasi dasar terhadap kompatibilitas komponen dan koneksi yang telah dibuat. |
| 15 | **Revision** | Jika rancangan belum sesuai, pengguna dapat kembali melakukan perubahan pada prototype 3D. |
| 16 | **Save Project** | Rancangan yang telah dibuat dapat disimpan agar dapat dibuka dan dikembangkan kembali. |
| 17 | **Project Information** | Sistem menampilkan informasi berupa arsitektur sistem, daftar komponen, dan fungsi setiap komponen. |
| 18 | **Export Project** | Pengguna dapat mengekspor hasil rancangan sebagai output dari proses perancangan IOTERA. |
| 19 | **Final Prototype** | Pengguna memperoleh rancangan awal IoT 3D yang dapat dijadikan acuan untuk pengembangan prototype fisik. |
